# Ikke-kvadratisk minesweeper
Prosjekt for å lage klassisk minesweeper, som windows versonen fra 1992, men med ikke-kvadratiske (og tilfeldige/forsjellige) ruter.

## Usage
Man kan enten kjøre .jar filen, eller kjøre koden under
```java
new Controller();
```
Koden er dårlig dokumentert, så GLHF med å forstå den :)

## Contributions
* All kode er skrevet av meg (selv om noen deler er med hjelp fra ai).
* Prosjekteret er inspirert av den klassiske windows versonene av spillet og mange sprites er hentet direkte derfra
